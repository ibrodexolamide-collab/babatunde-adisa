- WordPress
- DDEV
- Docker
- WSL2
- PHP
- JavaScript
- Git
- GitHub
- GitHub Actions

## Development Workflow

1. Select a task.
2. Create a feature branch.
3. Inspect the existing code.
4. Implement the task.
5. Test the changes.
6. Commit the changes.
7. Push the branch.
8. Create a pull request.
9. Review the changes.
10. Merge into main.
